# mydashboard

Стартовая страница: «Звёздная ночь» Ван Гога течёт через вихрь Balatro, стеклянные панели парят и чуть отступают от курсора, клик рассыпает искры.

**Адрес:** https://kamazichyo.github.io/mydashboard/

## Как править ссылки

Все сайты лежат в [`js/links.js`](js/links.js):

- `FAVORITES` — ряд крупных иконок в главной панели;
- `GROUPS` — панели по категориям.

Добавь строку `{ name: "Название", url: "https://..." },`, закоммить — через минуту GitHub Actions обновит сайт. Иконки подтягиваются сами (можно задать свою через `icon: "https://..."`).

## Поиск

- Клик по **G** или **Я** раскрывает поле. Можно просто начать печатать на странице — откроется последний поисковик. `Esc` закрывает.
- Картинку можно прикрепить скрепкой, вставить `⌘V` в поле или перетащить на страницу.
  - Google — картинка уходит прямо в Google Lens.
  - Яндекс не принимает картинки со сторонних сайтов, поэтому она копируется в буфер и открываются Яндекс Картинки — там нажми `⌘V`.

## Параметры

- `?pixel=220` — ретро-пиксели как в Balatro (число — плотность пикселей).

## Устройство

| файл | что делает |
|---|---|
| `js/background.js` | WebGL-шейдер: поле Balatro (React Bits) смещает картину + мерцание звёзд, закручивание вокруг курсора |
| `js/sparks.js` | Click Spark (React Bits) на canvas |
| `js/float.js` | парение панелей на пружине |
| `js/search.js` | раскрывающийся поиск с картинками |
| `assets/starry-night.jpg` | картина (общественное достояние, Wikimedia Commons) |

Без сборки и зависимостей: чистые HTML/CSS/JS. Локально: `python3 -m http.server` в папке и открыть `http://localhost:8000`.
