# mydashboard

Стартовая страница: «Звёздная ночь» Ван Гога течёт через вихрь Balatro. Сайты — облака из частиц с логотипами, «спроецированными» на них; облака медленно плывут, мягко расталкивают друг друга и замирают у курсора. Часы плавают в центре. Клик рассыпает искры.

**Адрес:** https://kamazichyo.github.io/mydashboard/

## Как править ссылки

Все сайты лежат в [`js/links.js`](js/links.js):

- `FAVORITES` — отдельные большие облака (`size` — размер, 1 = обычный);
- `GROUPS` — облака-группы: при наведении распаковываются в облачка-сайты, клик закрепляет.

Добавь строку `{ name: "Название", url: "https://..." },`, закоммить — через минуту GitHub Actions обновит сайт и сам скачает логотип (`tools/fetch-icons.mjs`). Свою картинку можно задать через `icon: "assets/icons/моя.png"`.

Клик по облаку, средняя кнопка и поиск всегда открывают новую вкладку, домашняя остаётся на месте.

## Поиск

- Клик по **G** или **Я** раскрывает поле. Можно просто начать печатать на странице — откроется последний поисковик. `Esc` закрывает.
- Картинку можно прикрепить скрепкой, вставить `⌘V` в поле или перетащить на страницу.
  - Google — картинка уходит прямо в Google Lens.
  - Яндекс не принимает картинки со сторонних сайтов, поэтому она копируется в буфер и открываются Яндекс Картинки — там нажми `⌘V`.

## Параметры

- `?pixel=220` — ретро-пиксели как в Balatro (число — плотность пикселей).
- `?paint=rhone` — начать с нужной картины; `?every=5` — менять каждые 5 секунд (для проверки).

## Устройство

| файл | что делает |
|---|---|
| `js/background.js` | WebGL-шейдер: поле Balatro (React Bits) смещает картину + мерцание звёзд, закручивание вокруг курсора |
| `js/clouds.js` | облака из частиц (WebGL2): форма, пушистость, проекция логотипов |
| `js/sky.js` | раскладка, физика, замирание у курсора, распаковка групп, клики |
| `js/sparks.js` | Click Spark (React Bits) на canvas |
| `js/search.js` | раскрывающийся поиск с картинками |
| `assets/starry-night.jpg` | картина (общественное достояние, Wikimedia Commons) |

Без сборки и зависимостей: чистые HTML/CSS/JS. Локально: `python3 -m http.server` в папке и открыть `http://localhost:8000`.

## Страница «Модели ИИ» (`models.html`)
Отдельная страница с тем же оформлением (картины Ван Гога, стекло, искры), открывается в новой вкладке облаком «Модели ИИ» на домашней. Виды: таблица (сортировка по заголовкам и из списка, группировка, фильтры по цене, рассуждению, прошедшим тест, поиск), карточки, график «цена и сила» с границей выгоды, раскладка по задачам, траты (по данным дашборда) и калькулятор. Данные: `js/models-data.js`, генерируется `python3 tools/build-models-data.py` из таблицы коэффициентов (`context/providers/baza-ai-notes.md`), замеров (`context/providers/bench/`: `bench.py`, `calib.py`, `gen_desc.py`) и `insights.json`. Параметры: `?view=chart|cards|tasks|spend`, `?scope=baza|claude|all`, `?sort=`, `?group=`, `?open=<id>`.
